# AM_Fall24
Repositorio para el parcial de la clase Aprendizaje de Máquina con Luis Felipe González

Este es un concurso de predicción de que haya menores en grupos reservas en hoteles para el grupo de Aprendizaje de Máquina 2024.

Los datos originales provienen de Hotel booking demand datasets, Antonio, de Almeida, Nunes

En este concurso usaremos varias características de las reservaciones para intentar predecir cuáles de ellas es probable que incluyan o no menores. Solo utilizamos aquellas reservaciones que no fueron canceladas según los datos originales.
